Gilded Hour is a top-down heist game: Rook, a gentleman thief, slips through the Meridian Gallery past patrolling guards and sweeping cameras, steals three treasures — the Sun Opal, the Jade Mask and the Gold Ledger — and escapes through the skylight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `game/` and `screenshots/` to the output directory and writes `dossier.json`. Node 22, standard library only, no network access.
